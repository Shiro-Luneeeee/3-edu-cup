# 请允我如夏日般融化

一款以成长、卡牌对局和人物关系为主线的叙事游戏。玩家从童年出发，在一回合又一回合的学习、游玩与相遇中积累能力，经历不同年龄的故事，并走向最终考试。游戏使用 Godot 4 制作。

## 游戏特色

- **有温度的画面。** 手绘感的场景、角色立绘、信纸与手写字共同构成游戏的视觉语言，让成长中的每一段相遇都像被收藏在夏日的日记里。
- **会留下记忆的声音。** 原创音乐与原创音效参与塑造游戏的节奏：从安静的卧室、翻开的纸页，到牌局中的行动与转折，声音陪着故事一起变化。
- **来自诗的灵感。** 莎士比亚第 18 首十四行诗中“我是否将你比作夏天”的发问，是游戏标题与情感表达的灵感之一。我们想描绘的，是人在成长中如何遇见、记住，也如何面对变化。
- **把成长写进牌局。** 牌局围绕推进考试进度与守护心态展开。玩家需要组建并升级卡组，在有限的回合与能量中安排进攻、防护和恢复；学习与日常选择也会影响之后的旅程。
- **可以走近的人物故事。** 视觉小说式的剧情以立绘、对白和场景变化呈现。不同角色在不同年龄与地点等待相遇，关系随着共同经历逐渐展开：
  - **月侧阳奈里**：在公园池塘边认识的女孩，开朗、爱看鱼，也会为自己的冒失认真道歉。
  - **伏见宫夜姬**：一丝不苟的同桌与班长，看似清冷，熟悉后却会露出细心又爱捉弄人的一面。
  - **白川花雪**：喜欢小狗和奇怪冷笑话的资优生，平时有点迷糊，重要时刻又格外体贴。
- **剧本之外的自由对话。** 游戏接入本地大模型，让玩家在已发生的剧情和角色设定之内与人物自由交谈。那些剧本没有写下的话，也能成为一段只属于自己的交流。

我们致力于将这个游戏打磨成自我审美与思考的表达。愿我们一起融化在夏日中。

## 游玩方式

1. 从主菜单开始新游戏，完成出生序章和取名。首次进入卧室时会出现操作引导。
2. 在卧室点击书架学习、游戏机游玩，或通过手机打开地图、社交、商店与画廊；笔记本用于卡牌升级。
3. 准备好后点击卧室的闹钟：有牌局的回合会进入牌局，其余回合会进入下一回合。随着年龄增长，地点、人物剧情和活动会逐步出现。
4. 从卧室左下角进入存档页。游戏提供三个存档槽，可在主菜单继续游戏。

社交页始终可以打开；认识角色后，对方会出现在好友列表。与角色自由对话时，每次**成功收到本地模型回复**增加 2 点好感度，每位角色每回合最多通过自由对话获得 10 点。达到上限后仍可聊天；进入下一回合后重新计算。自由对话不消耗精力，也不会推进人物剧情。第一次打开社交界面时，游戏会显示规则提示。

## 运行游戏

### Windows 发行版

下载并解压**完整发行文件夹**，从其中的游戏 `.exe` 启动。请保留 exe 旁的 `ai/` 文件夹；它包含离线对话需要的推理程序、模型与许可文本。仅复制 exe 无法使用内置模型。

本地模型功能会检查电脑内存和模型能否启动：物理内存低于 8 GB 时不会启用。若环境不支持，游戏会给出提示，其他剧情与玩法仍可继续。模型首次启动可能需要等待。

### 从源码运行

使用与工程匹配的 **Godot 4.8** 打开 `project.godot`，运行主场景 `scenes/main_menu.tscn`。本仓库不包含体积较大的模型权重和推理程序；开发时若要使用自由对话，可在本机启动 Ollama 并准备名称**精确为** `qwen3.5:4b` 的模型。游戏连接 `127.0.0.1:11434`，不会自动改用 `latest` 或其他模型。没有模型时也可以运行并体验非 AI 内容。

## 本地对话与存档

- 角色提示词由 `scripts/ai_role_prompts.gd` 根据年龄和已经发生的剧情构造；角色文案与回复格式见 [AI角色对话提示词.md](AI角色对话提示词.md)。
- 每位角色的最近 20 条对话消息、好感度、本回合自由对话奖励进度，以及首次提示状态，都会随游戏存档保存。
- 开发运行使用 `user://saves`，导出的独立游戏使用 `user://release_saves`。源码调试存档不会自动进入发行版。
- 模型与发行目录的详细配置、文件位置及组件来源见 [本地角色对话说明](docs/local_dialogue.md)。

## 导出 Windows 版本

在 Godot 中使用 `Windows Desktop` 预设导出游戏，然后按 [打包说明](docs/local_dialogue.md#打包-windows-评委版)将同版本的 `llama.cpp` Windows 运行文件、`Qwen3.5-4B` 的 GGUF 模型和相应许可文本放进 exe 旁的 `ai/` 目录。最终分发整个文件夹，并在没有 Ollama 的电脑上测试首次对话、场景切换和退出。

`.ignore/` 是本机导出与测试目录，已被 Git 忽略；从仓库克隆源码不会得到其中的发行包或模型。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `scenes/` | 菜单、卧室、牌局、社交和人物剧情场景 |
| `scripts/` | 游戏状态、回合、存档、对话及界面逻辑 |
| `data/` | 游戏数据资源 |
| `images/`、`audio/`、`fonts/` | 美术、音乐音效与字体资源 |
| `docs/` | 本地模型与开发记录 |

人物剧情原始文案位于项目根目录的 `月侧阳奈里 仅剧情.md`、`伏见宫夜姬 仅剧情.md` 和 `白川花雪.md`。
