# 本地角色对话

## 当前实现

- 社交页与现场社交页共用“自由对话”入口；已结识的月侧阳奈里可聊天。
- 卧室手机中的社交入口始终可打开。初遇任何人之前，好友列表显示“您的好友列表空空如也...........不是吗..........”。
- 三位角色的提示词由 `scripts/ai_role_prompts.gd` 按年龄和已完成剧情生成；原始文案与回复格式说明见项目根目录的 `AI角色对话提示词.md`。
- 对话历史保存在玩家存档中，最多保留最近 20 条消息；每次推理带最近 12 条。
- 每个角色每次成功收到本地模型回复，好感度增加 2 点；同一回合每个角色最多通过自由对话获得 10 点，达到上限后仍可继续聊天。额度随回合推进重置并写入存档。自由对话不消耗精力，也不推进剧情；社交界面已移除原“发消息 / 聊一会儿”入口和精力条。
- 每份存档第一次打开社交界面时，会以信纸提示自由对话的好感度规则；提示是否看过也随存档保存。
- 开始游戏时做内存和模型可用性检查；不可用时提示，原有玩法继续。

## 运行方式

1. Windows 发行文件夹内包含游戏 exe，以及 `ai/runtime/llama-server.exe`、同目录的运行 DLL、`ai/qwen3.5-4b-q4_k_m.gguf` 和许可文本。游戏优先使用这些离线文件。
2. 开发时若没有这些文件，连接 `127.0.0.1:11434` 的 Ollama，明确要求模型名 `qwen3.5:4b`，不会误用 `latest`。
3. 模型上下文为 4096 token，发行版只有一个推理并发槽；请求关闭思考模式，单次最多生成 240 token，以容纳括号动作、心理与角色台词。

## 打包 Windows 评委版

1. 在 Godot 中使用 `Windows Desktop` 预设导出 exe；导出模板需与当前 Godot 版本匹配。最终不要只发送 exe。
2. 在 exe 所在目录创建 `ai/runtime/`，放入同一版本的 llama.cpp Windows x64 Vulkan 发行包全部运行文件（包括 `llama-server.exe` 和 DLL）。
3. 将 4B 的 Q4_K_M GGUF 放在 `ai/qwen3.5-4b-q4_k_m.gguf`，同时放入模型与推理引擎的许可证文本。模型文件须核验 SHA256。
4. 在没有 Ollama 的 Windows 电脑上，从该文件夹启动游戏，检查模型可用性、首次回复、切换场景和退出后推理进程是否关闭。确认后压缩**整个文件夹**发送。

当前发行文件夹位于 `.ignore/out/v1123/`，包含用户导出的 `v1123.exe`、`ai` 模型与推理运行目录，以及使用说明。以前生成的 `.ignore/judge-build/` 和旧压缩包仍是旧版。发行目录被 Git 忽略，复制项目仓库不会自动带上模型和推理程序。`ai` 目录缺失时，其他游戏功能仍能使用，但本地自由对话需要开发机 Ollama。
